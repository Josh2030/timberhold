# Timberhold

A satisfying base-builder: chop trees, feed an endless supply of builders, and grow your camp — with the "why can't I stop playing" hooks (variable rewards, near-misses, streaks) borrowed from casino psychology, minus the gambling.

## Running it

It's a single self-contained HTML file (Three.js, embedded 3D models, local save/load). No build step, no dependencies.

- **Locally:** open `index.html` directly in a browser, or run a tiny local server (`python3 -m http.server`) and visit `http://localhost:8000`.
- **On GitHub Pages:** once this repo is pushed to GitHub with Pages enabled (Settings → Pages → Deploy from branch → `main` / root), it's served automatically at `https://<username>.github.io/<repo>/`.

## Editing

Open this folder in VS Code and edit `index.html` directly — everything (HTML, CSS, JS, and the embedded model data) lives in that one file.
